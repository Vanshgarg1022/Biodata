# Resume & Bio-data Website

A responsive multi-page personal website built with HTML5, CSS3 and JavaScript.

## Pages
- `index.html` — home page and navigation
- `resume.html` — resume with education, skills, projects and print-to-PDF option
- `biodata.html` — personal details, academic table and declaration
- `style.css` — responsive styling and print styles
- `script.js` — mobile navigation and dynamic footer year

## Run locally
Open `index.html` in a browser. No build tools or server are required.

## Customize
Replace placeholder text such as `Your Name`, email, phone, education, projects and dates with your own details. The avatar uses initials `YN`; change them in the HTML files.

## Host on GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `resume-biodata-website`.
2. Upload all five website files (`index.html`, `resume.html`, `biodata.html`, `style.css`, `script.js`) and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for deployment. GitHub Pages will show your public website URL in the Pages section, usually `https://YOUR-USERNAME.github.io/resume-biodata-website/`.

The website is static, so no backend or database is required. Do not publish sensitive personal information publicly.
